# Лид-магнит «Гид по форелевым платникам Подмосковья» — Ремингтон

PDF-гид для сбора email-адресов аудитории рыбаков интернет-магазина «Ремингтон».
Сегмент выбран по анализу форума rusfishing.ru (211 тыс. тем): форель — рыба №1
на форуме, платники — точка входа новичков, Московский регион — ядро аудитории.

## Файлы

| Файл | Что это |
|---|---|
| `gid-forel-podmoskovie.html` | Исходник гида (15 страниц A4, свёрстан под печать) |
| `gid-forel-podmoskovie.pdf` | Готовый PDF для выдачи за подписку |

## Структура гида (34 водоёма)

1. Обложка (брендинг «Ремингтон»)
2. Почему форель + 4 формата оплаты на платниках
3. Карта-схема: 22 платника по направлениям от МКАД
4. Каталог: Север — Дмитровское (3)
5. Каталог: Север — Ленинградское, Пятницкое (3)
6. Каталог: Запад — Новорижское, Ильинское (5)
7. Каталог: Юг — Калужское, Киевское, Симферопольское (3)
8. Каталог: Восток — Щёлковское, Новорязанское (5)
9. Каталог: Северо-восток — Ярославское, Фряновское, Горьковское (3)
10. Сводная таблица всех 22 платников
11. Мини-справочник: ещё 12 адресов
12. 7 правил и этикет платников
13. Стартовый сетап снастей («эриа»-ловля)
14. Сезонный календарь + чек-листы выезда и экипировки
15. CTA-страница с промокодом `FOREL-10`

Источники данных: анализ форума rusfishing.ru, обзор vc.ru (07.2026),
подборка РБК, каталог fishvodoem.ru, сайты водоёмов (osetrfarm.ru и др.).

## Как обновить

1. Правки — в HTML-файле (цены, список платников, промокод).
2. Пересборка PDF:
   ```bash
   chromium --headless --disable-gpu --no-sandbox \
     --print-to-pdf=gid-forel-podmoskovie.pdf --no-pdf-header-footer \
     file://$(pwd)/gid-forel-podmoskovie.html
   ```

## Важно

- Цены в гиде — ориентиры на начало сезона-2026, в тексте везде стоит
  дисклеймер «уточняйте на сайте водоёма». Перед новым сезоном обновить.
- Промокод `FOREL-10` — плейсхолдер: завести реальный код в CMS магазина
  до запуска рассылки.
