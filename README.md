# Лид-магнит «Гид по форелевым платникам Подмосковья» — Ремингтон

PDF-гид для сбора email-адресов аудитории рыбаков интернет-магазина «Ремингтон».
Сегмент выбран по анализу форума rusfishing.ru (211 тыс. тем): форель — рыба №1
на форуме, платники — точка входа новичков, Московский регион — ядро аудитории.

## Файлы

| Файл | Что это |
|---|---|
| `gid-forel-podmoskovie.html` | Исходник гида (14 страниц A4, свёрстан под печать) |
| `gid-forel-podmoskovie.pdf` | Готовый PDF для выдачи за подписку (кнопки «Сайт» и «Найти на карте» кликабельны) |
| `photos/NN.jpg` | Фото водоёмов для карточек (номер = номер карточки-источника в рабочей таблице) |
| `fonts/` | Bebas Neue (заголовки) и Open Sans (текст) — подключены через @font-face |

## Дизайн

Журнальный стиль по референсу ms-net.ru/portfolio/web/remington: Bebas Neue
для заголовков, Open Sans для текста, основной цвет #FF5E00, чёрные рамки
и прямоугольные формы, крупные фото. Логотип на обложке — типографский
плейсхолдер (заменить на фирменный SVG, когда будет файл).

## Структура гида (20 проверенных водоёмов, 14 страниц)

1. Обложка: лого, фото, ключевые цифры
2. Почему форель + 4 формата оплаты на платниках
3. Карта-схема: 20 платников по направлениям от МКАД
4. Каталог: Москва и север — Ленинградское (4)
5. Каталог: Запад — Новорижское (4)
6. Каталог: Юг — Каширское, Симферопольское (4)
7. Каталог: Юго-запад и ближнее Щёлковское (3)
8. Каталог: Восток — Щёлковское, Фряновское, Горьковское (3)
9. Каталог: Юго-восток — Новорязанское (2)
10. Сводная таблица всех 20 платников
11. 7 правил и этикет платников
12. Стартовый сетап снастей («эриа»-ловля)
13. Сезонный календарь + чек-листы выезда и экипировки
14. CTA-страница с промокодом `FOREL-10`

В каждой из 20 карточек: фото, тарифы с официальных прайсов (сняты 07.2026),
кнопки «Сайт» и «Найти на карте» (Яндекс.Карты).

Источники данных: анализ форума rusfishing.ru, рабочая таблица
«гид-таблица-карточек» с проверенными по сайтам водоёмов ценами (07.2026),
обзор vc.ru, подборка РБК, каталог fishvodoem.ru.

## Как обновить

1. Правки — в HTML-файле (цены, список платников, промокод).
2. Пересборка PDF:
   ```bash
   chromium --headless --disable-gpu --no-sandbox \
     --print-to-pdf=gid-forel-podmoskovie.pdf --no-pdf-header-footer \
     file://$(pwd)/gid-forel-podmoskovie.html
   ```

## Важно

- Цены в гиде — ориентиры на начало сезона-2026, в тексте везде стоит
  дисклеймер «уточняйте на сайте водоёма». Перед новым сезоном обновить.
- Промокод `FOREL-10` — плейсхолдер: завести реальный код в CMS магазина
  до запуска рассылки.
